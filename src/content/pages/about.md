## About Cosmolo

Cosmolo is an open-source GitHub template for building content-heavy static sites
with SvelteKit, MDSveX, and Zod-validated frontmatter. It is not a framework or a
plugin — it is a well-structured starting point that you clone, configure, and own.

- **Framework**: SvelteKit (Svelte 5, runes mode)
- **Content**: `.md` and `.svx` files
- **Validation**: Zod frontmatter schema
- **Output**: Static HTML via `@sveltejs/adapter-static`
